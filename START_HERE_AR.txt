1) ارفع الملفات العادية إلى جذر المستودع RentalManager.
2) أنشئ يدويًا هذين المسارين في GitHub (وقد أنشأتهما بالفعل):
   .github/workflows/telegram-reminders.yml
   scripts/telegram-reminders.js
3) انسخ محتوى الملفين من هذه النسخة إلى المسارين الصحيحين.
4) فعّل GitHub Pages من Settings > Pages > Deploy from a branch > main / root.
5) أضف Repository Secrets: TELEGRAM_BOT_TOKEN و TELEGRAM_CHAT_ID و FIREBASE_SERVICE_ACCOUNT و FIREBASE_DOCUMENT_ID.
6) افتح Actions وشغّل Telegram rental reminders يدويًا للاختبار.
