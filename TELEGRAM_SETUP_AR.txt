إعداد Telegram وGitHub Actions — RentalManager V10

داخل المستودع الجديد RentalManager أضف Repository Secrets التالية:

1. TELEGRAM_BOT_TOKEN
   التوكن الذي أعطاك إياه BotFather.

2. TELEGRAM_CHAT_ID
   رقم المحادثة الذي وجدته بواسطة getUpdates.

3. FIREBASE_SERVICE_ACCOUNT
   من Firebase Console:
   Project settings > Service accounts > Generate new private key
   افتح ملف JSON وانسخ محتواه بالكامل كقيمة للـ Secret.
   لا ترفع ملف Service Account إلى GitHub ولا ترسله لأي شخص.

4. FIREBASE_DOCUMENT_ID
   القيمة نفسها الموجودة في إعدادات التطبيق. القيمة الافتراضية:
   aladdin-rental-manager

المسار:
Settings > Secrets and variables > Actions > New repository secret

الاختبار:
Actions > Telegram rental reminders > Run workflow
اترك Send a Telegram test message مفعّلًا، ثم اضغط Run workflow.
يجب أن تصلك رسالة اختبار حتى لو لم يوجد تذكير مستحق.

بعد نجاح الاختبار، يعمل الفحص المجدول كل 5 دقائق. قد يتأخر التنفيذ بضع دقائق لأن GitHub لا يضمن التشغيل في الثانية المحددة.
